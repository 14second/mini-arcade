# Mini Arcade

Tiny browser games, each a single dependency-free HTML file. Play them in any browser — no installs, no ads, works offline once loaded.

- **Neon Runner** — cyberpunk endless runner: jump, duck, shoot.
- **Beat Tiles** — rhythm tapper where your taps play the melody.
- **Bubble Shooter** — aim and match three to pop the cluster.
- **Maze Chase** — clear the maze, dodge the sentries.
- **Traffic Hopper** — cross the traffic and ride the logs home.
- **Pixel Racer** — weave through traffic, near misses earn bonuses.

- **Snake** — the classic: eat, grow, don't bite yourself.
- **Pong** — first to 7 against the machine paddle.
- **Memory Match** — flip the cards, find all 8 pairs.
- **Breakout** — smash every brick, keep the ball alive.
- **Simon** — watch, listen, repeat the growing sequence.
- **Tower Stacker** — drop the sliding block, stack to the sky.
- **Fruit Catch** — catch the fruit, dodge the bombs.
- **Balloon Pop** — pop for points; the spiky red ones are traps.
- **Asteroid Blaster** — blast the rocks, thread the gaps.

Every game has synthesized music and sound effects generated in code — no audio files.
